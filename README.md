# Library Management System

A simple terminal-based Library Management System built with Python.

I created this project to practice and strengthen my Python fundamentals, especially Object-Oriented Programming.

## Features

* Add new books
* View all books
* Search books by title
* Search books by author
* Search books by ID
* Borrow books
* Return books
* Remove books
* View library statistics
* Generate unique book IDs

## Python Concepts Used

This project uses concepts including:

* Variables
* Strings
* Integers
* Booleans
* Lists
* `if`, `elif`, and `else`
* `for` loops
* `while` loops
* Functions
* Classes and objects
* `__init__`
* Methods
* User input
* Random number generation

## How It Works

The project contains two main classes:

### Book

Represents an individual book.

Each book contains:

* Title
* Author
* Book ID
* Availability status

### Library

Manages all the books in the system.

The Library class handles actions such as:

* Adding books
* Searching books
* Borrowing books
* Returning books
* Removing books
* Showing statistics

## Run the Project

Make sure Python is installed.

Run:

```bash
python main.py
```

Then select an option from the terminal menu.
